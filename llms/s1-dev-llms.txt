## Search engines
Each engine is a `search_service` value on the same Search endpoint; the response shape is identical and the `snippet` contract differs per engine.
- [Google Search API](https://s1.dev/google-search-api): Default engine. General web results, with optional page content in the same request.
- [Bing Search API](https://s1.dev/bing-search-api): Bing web results after Microsoft retired its own Search API v7 on 2025-08-11.
- [DuckDuckGo Search API](https://s1.dev/duckduckgo-search-api): A second general index for cross-checking a Google result set.
- [Yahoo Search API](https://s1.dev/yahoo-search-api): Yahoo web results. Supplied by Bing under their search alliance, so expect heavy overlap.
- [Yandex Search API](https://s1.dev/yandex-search-api): A third general index, especially Russian-language and CIS coverage. `published_date` is a UTC timestamp when `time_range` is set.
- [GitHub Search API](https://s1.dev/github-search-api): Repositories, issues, pull requests, and discussions. Each result has `kind`; repos add `stars`/`language`, threads add `num_comments`.
- [arXiv Search API](https://s1.dev/arxiv-search-api): Papers and preprints. Snippet is `authors | ISO date | abstract`.
- [Reddit Search API](https://s1.dev/reddit-search-api): Posts and discussion. Snippet is `r/subreddit | /u/author | post text`.
- [X Search API](https://s1.dev/x-search-api): Posts. Title carries the display name and `@handle`; snippet is the post text.
- [YouTube Search API](https://s1.dev/youtube-search-api): Videos. Snippet is `channel | runtime | description`.
- [Wikipedia Search API](https://s1.dev/wikipedia-search-api): Reference articles. Snippet is an extract from the article body.
- [IMDb Search API](https://s1.dev/imdb-search-api): Films and television. Snippet is `Rank: N | year | top-billed cast`.
- [WeChat Search API](https://s1.dev/wechat-search-api): Official Account articles. Snippet is `account name | date | excerpt`; article bodies via `crawl_results`.
- [Bilibili Search API](https://s1.dev/bilibili-search-api): Chinese-language video. Snippet is `uploader | runtime | description`.
- [Baidu Search API](https://s1.dev/baidu-search-api): Chinese web, including Baidu Baike and state media.
- [Bing China Search API](https://s1.dev/bingcn-search-api): Bing’s Mainland China ranking, distinct from international `bing` and from `baidu`. Native `page` pagination.
- [360 Search API](https://s1.dev/360-search-api): A second Chinese index, distinct from Baidu; useful for corroboration.
- [Quark Search API](https://s1.dev/quark-search-api): A third Chinese index, leaning on Alibaba and UC content.

## Crawl coverage
Per-site pages for the Crawl endpoint. Support is measured per URL pattern; each page publishes the matrix verified against the live crawler, plus real request/response samples.
- [LinkedIn Scraper API](https://s1.dev/linkedin-scraper-api): Public company pages, jobs, posts, articles, and public profiles to Markdown; login-walled URLs return AUTH_REQUIRED.
- [Reddit Scraper API](https://s1.dev/reddit-scraper-api): Posts with comment threads, subreddit listings, and user activity feeds to Markdown via Reddit's public Atom feeds — no account or OAuth app.
- [X Scraper API](https://s1.dev/x-scraper-api): Tweets, quote tweets, and long-form Articles to Markdown via public embed/syndication JSON — no X account needed.
- [YouTube Scraper API](https://s1.dev/youtube-scraper-api): Watch/short URLs to timestamped transcripts and playlists to structured listings via the page's caption track — no Google account.
- [GitHub Scraper API](https://s1.dev/github-scraper-api): Repo READMEs, blob file views, and raw.githubusercontent.com files to clean Markdown — no GitHub account.
- [Stack Overflow Scraper API](https://s1.dev/stackoverflow-scraper-api): Questions with full answer threads via the public Stack Exchange API — covers stackoverflow.com plus *.stackexchange.com, Ask Ubuntu, Super User, Server Fault, MathOverflow.
- [Hugging Face Scraper API](https://s1.dev/huggingface-scraper-api): Model and dataset cards to Markdown plus Space metadata via the public Hub API; gated repos return honest metadata-only results.
- [WeChat Scraper API](https://s1.dev/wechat-scraper-api): Public official-account articles to Markdown with account, publish time, and image URLs — captcha hits return a named ANTI_BOT error.
- [Hacker News Scraper API](https://s1.dev/hackernews-scraper-api): Stories with full comment trees, comment permalinks with reply subtrees, and front-page/ask listings via the public Algolia-hosted HN API.
- [npm Scraper API](https://s1.dev/npm-scraper-api): Package pages — README, version, license, weekly downloads, dependency list — via the public registry.npmjs.org API; scoped and version-pinned URLs covered.
- [PyPI Scraper API](https://s1.dev/pypi-scraper-api): Project pages — README, license, requires-python, requirements list — via the public pypi.org JSON API; pinned-release URLs covered.
- [Bilibili Scraper API](https://s1.dev/bilibili-scraper-api): Video pages — title, description, publish time, engagement stats, and timestamped danmaku comments — via a dedicated parser; b23.tv short links resolve to the same card.
- [CSDN Scraper API](https://s1.dev/csdn-scraper-api): Blog articles — full body text as Markdown — via cloudflare-fetch plus a dedicated parser; /article/details/ URLs verified.
